Keycloak Authentication Setup

Add OIDC login to the Licensing MCP agent host. Keycloak proves identity; the existing code handles authorization (roles, permissions, audit).

Authentication vs. Authorization — The Split

Keycloak handles authentication only — "Who are you?" Login, password verification, JWT with email.
The existing MCP server handles authorization — identity.py resolves the email against cs_users, cs_permissions table maps roles to tools, cs_executor.py gates every write and logs audit. None of that changes.

Prefer the one-command setup. The keycloak/ folder has a docker-compose.yml + pre-built realm export that creates the realm, client, and the three correct users automatically — cd keycloak && docker compose up -d. See keycloak/README.md. The manual steps below are the explainer for what that import does.

4.2 New File: agent/auth.py

Single responsibility: fetch Keycloak's public keys, validate the JWT, return the email. Nothing else.

"""
Keycloak OIDC authentication — validates JWTs and extracts email.
Authorization (roles, permissions) is handled by the MCP server's own code.
"""
from functools import lru_cache
import httpx
from jose import JWTError, jwt

KEYCLOAK_URL = "http://localhost:8080"
REALM = "licensing-mcp"
CLIENT_ID = "licensing-agent"
ISSUER = f"{KEYCLOAK_URL}/realms/{REALM}"
JWKS_URL = f"{ISSUER}/protocol/openid-connect/certs"


@lru_cache(maxsize=1)
def get_jwks() -> dict:
    response = httpx.get(JWKS_URL)
    response.raise_for_status()
    return response.json()


def validate_token(token: str) -> dict:
    try:
        return jwt.decode(
            token, get_jwks(), algorithms=["RS256"],
            issuer=ISSUER, options={"verify_aud": False},
        )
    except JWTError as e:
        raise ValueError(f"Token validation failed: {e}")


def get_actor_email(token: str) -> str:
    """Validate token and return email. This becomes CS_ACTOR_ID."""
    claims = validate_token(token)
    email = claims.get("email") or claims.get("preferred_username")
    if not email:
        raise ValueError("Token missing email claim — check Keycloak client scope mapper")
    return email

4.4 Rewrite agent/app.py

The global bridge and lifespan are replaced by per-session bridges. Three new in-memory stores, a session helper, and four new endpoints.

New state + helpers

# Three dicts replace the old single global bridge
sessions: dict[str, list] = {}                # session_id → message history
authenticated_sessions: dict[str, dict] = {}  # session_id → {email: ...}
session_bridges: dict[str, MCPBridge] = {}    # session_id → MCPBridge

async def _get_bridge(session_id: str) -> MCPBridge:
    """Lazily start a per-session MCP subprocess on first tool call."""
    if session_id not in session_bridges:
        email = authenticated_sessions[session_id]["email"]
        bridge = MCPBridge(actor_email=email)
        await bridge.start()
        session_bridges[session_id] = bridge
    return session_bridges[session_id]

def _session_id(request: Request) -> str | None:
    """Return the session_id cookie if it maps to an authenticated session."""
    sid = request.cookies.get("session_id")
    return sid if sid and sid in authenticated_sessions else None

# Lifespan: only cleanup on shutdown (no startup bridge)
@asynccontextmanager
async def lifespan(app: FastAPI):
    yield
    for bridge in session_bridges.values():
        await bridge.stop()

/login — redirect to Keycloak

@app.get("/login")
async def login():
    auth_url = (
        f"{ISSUER}/protocol/openid-connect/auth"
        f"?client_id={CLIENT_ID}"
        f"&response_type=code"
        f"&redirect_uri=http://localhost:8100/callback"
        f"&scope=openid email"
        f"&prompt=login"  # always show login form — allows switching users
    )
    return RedirectResponse(auth_url)

/callback — exchange code for token, create session

@app.get("/callback")
async def callback(code: str):
    async with httpx.AsyncClient() as http:
        resp = await http.post(
            f"{ISSUER}/protocol/openid-connect/token",
            data={
                "grant_type": "authorization_code",
                "client_id": CLIENT_ID,
                "code": code,
                "redirect_uri": "http://localhost:8100/callback",
            },
        )
    actor_email = get_actor_email(resp.json()["access_token"])
    session_id = str(uuid.uuid4())
    authenticated_sessions[session_id] = {"email": actor_email}
    response = RedirectResponse("/")
    response.set_cookie("session_id", session_id, httponly=True)
    return response

/logout — clear session, redirect home

Logout redirects to / (not Keycloak's end-session endpoint). The &prompt=login on /login ensures Keycloak always asks for credentials, so switching users works correctly without needing the end-session redirect.

@app.get("/logout")
async def logout(request: Request):
    session_id = request.cookies.get("session_id")
    if session_id:
        bridge = session_bridges.pop(session_id, None)
        if bridge:
            try:
                await bridge.stop()
            except Exception:
                pass  # subprocess may have already exited
        authenticated_sessions.pop(session_id, None)
        sessions.pop(session_id, None)
    response = RedirectResponse("/")
    response.delete_cookie("session_id")
    return response

Protected /api/chat and /api/chat/reset

class ChatRequest(BaseModel):
    message: str  # session_id removed — session comes from cookie

@app.post("/api/chat")
async def chat(req: ChatRequest, request: Request):
    session_id = _session_id(request)
    if not session_id:
        return Response(status_code=401, content="Not authenticated")
    messages = sessions.setdefault(session_id, [])
    bridge = await _get_bridge(session_id)
    messages.append({"role": "user", "content": req.message})
    reply, tool_trace = await run_agent_turn(client, bridge, messages)
    return {"reply": reply, "tool_calls": tool_trace}

@app.post("/api/chat/reset")
async def reset_chat(request: Request):
    """Clear message history (New Chat button)."""
    session_id = _session_id(request)
    if session_id:
        sessions[session_id] = []
    return {"ok": True}

Protected /api/tools

@app.get("/api/tools")
async def tools(request: Request):
    session_id = _session_id(request)
    if not session_id:
        return Response(status_code=401, content="Not authenticated")
    bridge = await _get_bridge(session_id)
    return {
        "actor": authenticated_sessions[session_id]["email"],
        "tools": [...],
    }

The Flow

Browser | Click "Sign in" → GET /login | Redirected to Keycloak login page | User enters credentials | Keycloak redirects → GET /callback?code=... | Agent host exchanges code → JWT → extracts email | Sets httponly session cookie → redirects to / v Agent Host (FastAPI, port 8100) | /api/tools 401 check → show login overlay if not authenticated | /api/chat: reads session cookie → gets bridge for session | Spawns MCP subprocess with CS_ACTOR_ID=email (lazy, on first message) v MCP Server (subprocess, stdio) | identity.py: reads CS_ACTOR_ID → looks up cs_users → cs_role_members | cs_permissions: role → allowed tools | cs_executor.py: gate → mutate → audit → commit v SQLite (owns ALL authorization decisions)

Architecture Summary

Browser | Login -> Keycloak (authentication) | Returns JWT with email claim v Agent Host (FastAPI, port 8100) | Validates JWT signature (Keycloak JWKS) | Extracts email from token | Spawns MCP subprocess with CS_ACTOR_ID=email v MCP Server (subprocess, stdio) | identity.py reads CS_ACTOR_ID | Looks up user in cs_users table | Looks up role in cs_role_members table | cs_permissions table: role -> allowed tools | cs_executor.py: gate -> mutate -> audit v SQLite Database (owns ALL authorization decisions)

Clear boundary: Keycloak = "you are rep.sarah@mathworks.com" (authentication). The database = "rep.sarah is CS-L1 and can call revoke_activation" (authorization). These concerns never mix.
